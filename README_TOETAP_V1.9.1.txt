TOETAP V1.9.1 — AUTO REFRESH STRAVA GEAR ON RETURN

Base: TOETAP V1.9

- Clicking CREATE NEW GEAR ON STRAVA marks the current TOETAP session as waiting for new gear.
- When the user returns/focuses TOETAP, the existing gear refresh is triggered automatically.
- Add Shoe, Edit Shoe, and Link Strava Gear are covered.
- Manual REFRESH GEAR remains as fallback.
- Form data stays on the current page.
- No SQL migration required.
- NFC / Latest Tap Wins / webhook flow unchanged.
