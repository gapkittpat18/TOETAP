TOETAP V1.4 — STRAVA-FIRST ONBOARDING
======================================
This release makes the product position visible in the actual UX.

First use with no Strava connection:
1. User sees TOETAP onboarding.
2. CONNECT STRAVA is the recommended/default path.
3. CONTINUE WITHOUT STRAVA is always available.
4. Skipping Strava never blocks TOETAP.
5. Settings keeps Connect Strava available later.

Connected users:
- No onboarding interruption.
- Existing Strava-first Home/Insights/mileage behavior remains.

No-Strava users:
- Existing V1.2 fallback remains.
- Manual Add Run remains.
- Shoes / NFC / Tags remain usable.

No SQL changes in V1.4.
Core NFC matching and webhook files are untouched.
