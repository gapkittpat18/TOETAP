TOETAP V2.0.3 — COST/KM UX

- CURRENT COST / KM = purchase price / current mileage.
- If price exists but mileage is 0, show "Not started" instead of "—".
- TARGET COST / KM = purchase price / target lifespan.
- Shoes page shows Current/km and Target/km directly on each shoe card.
- Remaining km stays visible in the card footer.
- No SQL changes required after V2.0 migration.

Example:
Purchase price: THB 3,990
Mileage: 0 km
Target: 400 km
Current cost/km: Not started
Target cost/km: THB 9.98
