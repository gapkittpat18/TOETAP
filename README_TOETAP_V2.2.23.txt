TOETAP V2.2.23 — CUSTOM SHOE PHOTO

Flow:
Shoe → Add Shoe Photo → Photo Library / Take Photo → Preview → Use This Photo.

Features:
- Mobile camera capture and photo-library upload.
- Preview before save.
- JPG, PNG, WebP validation; max 10 MB.
- Random server filenames and executable-upload blocking.
- User can only modify their own shoe.
- Replace/remove photo.
- Custom photo shown on Shoe Detail, Shoes rotation and Home current-shoe hero.
- Existing sneaker asset remains fallback.
- Original image is retained so background removal can be added next.

INSTALL
1. Run v223_custom_shoe_photo.sql once.
2. Deploy package files.
3. Ensure uploads/shoes is writable by PHP/Apache.

No NFC, ownership, Strava, webhook, matching or activity logic changes.
Auto background removal is not included yet.
