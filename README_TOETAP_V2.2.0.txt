TOETAP V2.2.0 — SHOE TIMELINE + MILESTONES

New on shoe detail:
- SHOE JOURNEY / MILESTONES timeline.
- ACTIVATED milestone.
- 50 KM, 100 KM, 250 KM and 500 KM milestones.
- FULL VALUE milestone based on the shoe target mileage.
- PR SHOE milestone when the existing Shoe Performance Profile has a Strava PR for 5K/10K/21K/42K.
- Completed milestones use TOETAP lime; future milestones show distance remaining.
- Uses data already available on shoe.php; no extra Strava scan.
- No SQL migration.
- No NFC / Latest Tap Wins / webhook changes.

Note:
This is the first milestone layer. A future durable event-history table can support exact dates
for first run, each mileage crossing, historical PR progression, retirement, and shareable achievements.
